# note-agent

把截图和短文本自动整理成本地知识库，并基于知识库回答问题。

- **录入**：粘贴截图或一段文字 → 模型拆成若干条笔记 → **自动归到「大块 › 小块」两层分类里** → 写成 Markdown 存进 vault
- **提问**：先在知识库里检索相关笔记，再让模型基于笔记回答并标出引用；没检索到时会明确标出「来自模型自身知识」
- **笔记**：左边是分类目录，右边是该分类的笔记索引；可以搜索、查看笔记（含原始截图和双链）、调整分类
- **设置**：切换接口地址、密钥和模型

笔记是普通的 Markdown 文件，存在与本仓库平级的 `../vault/`，每次改动都会在 vault 里做一次 git 提交。
要做成什么样见 [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)。

## 启动

需要先装好 [uv](https://docs.astral.sh/uv/) 和 Node.js。

1. 配置密钥（二选一）：
   - 把 `.env.example` 复制成 `.env`，填上 `ZHIPU_API_KEY`；或者
   - 先启动，再到界面的「设置」页填写
2. 双击 `start.bat`。它会开两个窗口分别跑后端和前端，然后打开 <http://localhost:5173>。
   关掉这两个窗口就是停止。

手动启动的话，开两个终端：

```bash
cd backend
uv run uvicorn app.main:app --port 8000
```

```bash
cd frontend
npm install   # 只有第一次需要
npm run dev
```

第一次用建议先到「设置」页点「保存并测试连接」，确认两个模型都能用。

## 使用提示

- 一张截图会变成 1 条**主题笔记**（保留原来的流程、表格、层次）加若干条**概念笔记**；只讲一个概念的输入只出概念笔记。
  模型用自己的知识补充的内容单独放在笔记的「模型补充」区块里，不会和你的资料混在一起。
- **录入是排队的**：贴好截图（可以连着贴好几张）或文字，点「加入队列」就行，不用等它处理完，可以接着放下一份。
  后台一份一份按顺序处理，一张截图大约 10–40 秒。「录入」标签上的数字是还没处理完的份数；
  在别的页面时，处理完会在右下角提示。队列存在硬盘上，关掉应用再打开会接着处理。
- **长文档**：可以把 PDF、Markdown、纯文本文件拖进来（单个不超过 30 MB），或者直接粘贴一大段文字。
  2000 字以上的内容按「摘要级」处理：一条主题笔记（摘要加大纲）和几条关键概念笔记，不逐句保留原文。
  原文件会存进知识库的 `assets/` 目录，从笔记里可以点开。几万字的文档要一两分钟，队列里会显示读到第几段。
- **网页链接**：在文本框里贴网址（一行一个）就会去抓取网页正文，同样按摘要级处理。笔记里只记网址，不保存网页全文。
  需要登录才能看的页面、内容靠脚本加载的页面抓不到，会提示失败——那种请用截图。
- 队列里排着的可以取消，失败的可以重试。同一份内容重复录入会被识别出来，可以选择「重新处理」。
- **笔记可以随时改**：点开笔记可以编辑标题、概要、别名和正文，也可以删除；「笔记」页的「新建笔记」可以自己手写一条。
  改标题时，别的笔记里指向它的链接会跟着改。删除和合并在应用里不能撤销（知识库是 git 仓库，需要时可以用 git 找回）。
- **疑似重复**：新录入的概念和知识库里已有的某条同名（或和它的别名相同）时，新笔记照常存下并标上「疑似重复」。
  点「对比并处理」会把两条笔记并排摆出来，由你选：保留已有的、保留新的、两条都留，或者合并成一条。
  可以录入完当场处理，也可以以后在「笔记」页的「疑似重复」里逐条处理。
- **分类是全自动的**：录入时模型会沿用已有的分类，没有合适的就新建，不需要确认。
  模型拿不准的少数笔记会进「待整理」，点开可以确认它猜的分类或改到别处。
- **分类可以随时手改**：在笔记弹窗里「改分类」，或在「笔记」页给分类改名（改成同层已有的名字即合并）、
  新建、删除空分类。你手动改过的地方会带一把小锁，模型以后不会再动它。
- 「全部重排」会让模型重新设计分类并给所有未锁定的笔记重新归类，目录可能大变样。
- **三种看法**：「笔记」页右上角可以在列表、图谱、导图之间切换，看的范围跟着左边目录选的分类走。
  - **图谱**：一条笔记一个点，互相有链接就连线。大圆点是主题笔记，颜色按分类区分，虚线圈是别的分类里和这里有链接的笔记。
    可以拖动点、拖动空白处平移、滚轮缩放；鼠标指着一个点会高亮它的邻居，点一下打开笔记。超过 500 条时请先选小一点的范围。
  - **导图**：从左到右的树，大块 → 小块 → 主题笔记 → 概念笔记。点分类或它右边的圆钮展开、收起，点笔记打开。
    笔记多的时候默认只展开到大块或小块，自己点开要看的那一支。
- 从旧版本升级：旧笔记都在「待整理」里，到那里点「让模型再归类一次」即可。
- 在应用之外改过笔记文件后，到「笔记」页点「同步」（重启后端也会自动同步）。

## 目前的限制

- 扫描件 PDF（没有文字层）读不了，请改用截图。超过 20 万字的文档只处理前 20 万字。
- 抓网页只是发一次普通请求：知乎、微信公众号这类要登录或有反爬限制的网站多半抓不到。
- 长文档只做摘要级整理，不保存全文用于检索——问答答不到原文里的细节。
- 检索是字面匹配加模型扩展检索词，没有向量检索；笔记超过几百条后效果会下降。
- 疑似重复只按名字判断：名字不同但讲同一件事的两条笔记发现不了。
- 只在本机使用：后端没有登录和权限控制，不要暴露到公网。
