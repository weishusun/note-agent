# note-agent

把截图和短文本自动整理成本地知识库，并基于知识库回答问题。

- **录入**：粘贴截图或一段文字 → 模型拆成若干条笔记 → **自动归到「大块 › 小块」两层分类里** → 写成 Markdown 存进 vault
- **提问**：先在知识库里检索相关笔记，再让模型基于笔记回答并标出引用；没检索到时会明确标出「来自模型自身知识」
- **笔记**：左边是分类目录，右边是该分类的笔记索引；可以搜索、查看笔记（含原始截图和双链）、调整分类
- **设置**：连上模型服务商（智谱、DeepSeek、阿里云百炼、硅基流动、火山方舟，或任何 OpenAI 兼容的），选各环节用的模型

笔记是普通的 Markdown 文件，存在知识库文件夹里：桌面版第一次打开时自己选，浏览器开发方式默认是与本仓库平级的 `../vault/`。
知识库文件夹是 git 仓库的话，每次改动都会自动提交一次。
要做成什么样见 [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)。

## 桌面版

平时用桌面版：一个独立窗口，不用开命令行，也不用开浏览器。

**打包**（改了代码之后重新打包也是这两步）：

```bash
cd desktop
npm install   # 只有第一次需要，会下载 Electron（约 100 MB）
npm run build
```

下载 Electron 很慢的话，先在同一个 PowerShell 里设镜像再 `npm install` / `npm run build`：
`$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"`。
打包要用到 `backend/.venv` 里的 PyInstaller，没有的话先在 `backend` 下运行 `uv sync --group build`。

打包结果在 `desktop/release/note-agent/`。把**整个文件夹**复制到一个固定的地方（比如 `D:\Apps\知识库\`），
双击里面的 `note-agent.exe`：

1. 第一次打开会请你选知识库文件夹。选原来的 `D:\noteagent\vault` 就能接着用已有的笔记；也可以新建一个空文件夹。
   勾上「在桌面创建快捷方式」，以后从桌面打开（快捷方式指向 exe 所在的位置，所以先把文件夹放好再第一次打开）。
2. 到「设置」页点一家服务商，粘贴它的 API Key，点「连接」：各环节的模型会按推荐自动填好，再点「保存并测试」。
   桌面版不读 `.env`，设置存在 `%APPDATA%\note-agent\settings.json`，和浏览器开发方式的设置互不影响。

- 关窗口就是退出。录入还没处理完时会先问一句，退出后下次打开接着处理。
- 只能开一个，再双击会切回已经开着的窗口。
- 换知识库：设置页「知识库位置」→「更换…」，应用会重新打开。
- 出问题时看日志：`%APPDATA%\note-agent\logs\backend.log`（启动失败的提示框里有按钮直接打开）。
- 更新：重新打包后，关掉应用，用新的 `release/note-agent` 文件夹覆盖旧的。笔记和设置都不在这个文件夹里，不受影响。

## 浏览器开发方式

需要先装好 [uv](https://docs.astral.sh/uv/) 和 Node.js。

1. 配置密钥（二选一）：
   - 把 `.env.example` 复制成 `.env`，填上 `ZHIPU_API_KEY`；或者
   - 先启动，再到界面的「设置」页填写
2. 双击 `start.bat`。它会开两个窗口分别跑后端和前端，然后打开 <http://localhost:5173>。
   关掉这两个窗口就是停止。

手动启动的话，开两个终端：

```bash
cd backend
uv run uvicorn app.main:app --port 8000
```

```bash
cd frontend
npm install   # 只有第一次需要
npm run dev
```

第一次用建议先到「设置」页点「保存并测试」，确认几个模型都能用。

**设置页怎么用**：

- 先在「模型服务商」里点一家，照提示去它的网站创建 API Key，粘贴进来点「连接」。Key 只发给你选的那一家，
  连上后会列出它能用的模型，并按推荐把看图、文字、向量三个环节填好。
- 每个环节可以用不同的服务商：比如文字用 DeepSeek，看图和向量用智谱。DeepSeek 没有向量模型，向量那一行选别家或者不用。
- 模型名可以从候选里选，也可以照服务商的文档自己填；写错了（服务商的列表里没有）会标红提示。
- 推荐模型写在 `backend/app/providers.yaml` 里。只有智谱是实测过的，其他几家按官方文档整理，模型可能已经改名，
  以「保存并测试」的结果为准。
- 向量模型不选也能用，只是检索只按字面匹配。选了之后已有的笔记会在后台补算向量，设置页能看到进度。

## 使用提示

- **界面**：左栏是各个页面（笔记、录入、提问、图谱、导图）和整个知识库的分类目录；笔记页中间是列表，右边直接读全文。
  在任何页面按 **Ctrl K** 呼出输入面板：输关键词搜笔记、输一句话提问，或者直接粘贴截图、网址、一段文字录入。
  配色跟随系统的浅色或深色模式。
- 一张截图会变成 1 条**主题笔记**（保留原来的流程、表格、层次）加若干条**概念笔记**；只讲一个概念的输入只出概念笔记。
  模型用自己的知识补充的内容单独放在笔记的「模型补充」区块里，不会和你的资料混在一起。
- **模型补充**：录入完，笔记先出来；随后队列里会多一个「模型补充」任务，给这次的概念笔记（和截图的主题笔记）各写一段 600–1000 字的讲解（是什么、原理、例子、易混淆的……结构由模型定），几条一起写，通常半分钟左右。不满意或旧笔记想补，点阅读区右上角的 ✦ 按钮「重新写模型补充」。
- **录入是排队的**：贴好截图（可以连着贴好几张）或文字，点「加入队列」就行，不用等它处理完，可以接着放下一份。
  后台一份一份按顺序处理，一张截图大约 10–40 秒。左栏「录入」旁的数字是还没处理完的份数；
  在别的页面时，处理完会在右下角提示。队列存在硬盘上，关掉应用再打开会接着处理。
- **长文档**：可以把 PDF、Markdown、纯文本文件拖进来（单个不超过 30 MB），或者直接粘贴一大段文字。
  2000 字以上的内容按「摘要级」处理：一条主题笔记（摘要加大纲）和几条关键概念笔记，不逐句保留原文。
  原文件会存进知识库的 `assets/` 目录，从笔记里可以点开。几万字的文档要一两分钟，队列里会显示读到第几段。
- **网页链接**：在文本框里贴网址（一行一个）就会去抓取网页正文，同样按摘要级处理。笔记里只记网址，不保存网页全文。
  需要登录才能看的页面、内容靠脚本加载的页面抓不到，会提示失败——那种请用截图。
- 队列里排着的可以取消，失败的可以重试。同一份内容重复录入会被识别出来，可以选择「重新处理」。
- **笔记可以随时改**：阅读区右上角可以编辑标题、概要、别名和正文，改分类，或者删除；笔记列表上方的「新建笔记」可以自己手写一条。
  改标题时，别的笔记里指向它的链接会跟着改。删除和合并在应用里不能撤销（知识库是 git 仓库，需要时可以用 git 找回）。
- **疑似重复**：新录入的概念和知识库里已有的某条同名（或和它的别名相同）时，新笔记照常存下并标上「疑似重复」。
  配了向量模型的话，名字不同但内容很接近的也会被找出来：先按向量找出最接近的已有笔记，再让模型判断是不是同一个概念。
  模型偶尔会把「相关但不同」的两条也标上，那种选「两条都留」就行。
  点「对比并处理」会把两条笔记并排摆出来，由你选：保留已有的、保留新的、两条都留，或者合并成一条。
  可以录入完当场处理，也可以以后在左栏的「疑似重复」里逐条处理。
- **分类是全自动的**：录入时模型会沿用已有的分类，没有合适的就新建，不需要确认。
  模型拿不准的少数笔记会进「待整理」，点开可以确认它猜的分类或改到别处。
- **分类可以随时手改**：在阅读区「改分类」，或者选中一个分类后在列表上方给它改名（改成同层已有的名字即合并）、
  新建、删除空分类。你手动改过的地方会带一把小锁，模型以后不会再动它。
- 「全部笔记」列表上方的「全部重排」会让模型重新设计分类并给所有未锁定的笔记重新归类，目录可能大变样。
- **提问可以追问**：「提问」页是一段连续的对话，答完可以接着问「它和刚才那个有什么区别」「再详细一点」，
  模型会先结合上文弄清你在问什么，再去知识库里检索。这段对话存在浏览器里，刷新不丢；点「新对话」清空重来。
  过去的对话不保存。
- **三种看法**：笔记、图谱、导图三个页面看的范围都跟着左栏目录里选的分类走。
  - **图谱**：一条笔记一个点，互相有链接就连线。大圆点是主题笔记，颜色按分类区分，虚线圈是别的分类里和这里有链接的笔记。
    可以拖动点、拖动空白处平移、滚轮缩放；鼠标指着一个点会高亮它的邻居，点一下打开笔记。超过 500 条时请先选小一点的范围。
  - **导图**：从左到右的树，大块 → 小块 → 主题笔记 → 概念笔记。点分类或它右边的圆钮展开、收起，点笔记打开。
    笔记多的时候默认只展开到大块或小块，自己点开要看的那一支。
- 从旧版本升级：旧笔记都在「待整理」里，到那里点「再归类一次」即可。
- 在应用之外改过笔记文件后，点笔记列表上方的「同步」（重启后端也会自动同步）。

## 目前的限制

- 扫描件 PDF（没有文字层）读不了，请改用截图。超过 20 万字的文档只处理前 20 万字。
- 抓网页只是发一次普通请求：知乎、微信公众号这类要登录或有反爬限制的网站多半抓不到。
- 长文档只做摘要级整理，不保存全文用于检索——问答答不到原文里的细节。
- 向量检索要调用服务商的向量接口：笔记内容会发过去（录入时本来也发），没网时新笔记暂时没有向量，联网后自动补上。
- 没配向量模型时，疑似重复只按名字判断：名字不同但讲同一件事的两条笔记发现不了。
- 只在本机使用：后端没有登录和权限控制，不要暴露到公网。
- 桌面版约 380 MB，大部分是 Electron 自带的浏览器内核。没有安装包和自动更新，新版本要自己重新打包覆盖。
