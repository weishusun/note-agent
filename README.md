# note-agent

把截图和短文本自动整理成本地知识库，并基于知识库回答问题。

- **录入**：粘贴截图或一段文字 → 模型拆成若干条原子笔记 → 写成 Markdown 存进 vault，并在 vault 里做一次 git 提交
- **提问**：先在知识库里检索相关笔记，再让模型基于笔记回答并标出引用；没检索到时会明确标出「来自模型自身知识」
- **笔记**：浏览、搜索、查看笔记（含原始截图和双链）
- **设置**：切换接口地址、密钥和模型

笔记是普通的 Markdown 文件，存在与本仓库平级的 `../vault/`，可以直接用 Obsidian 打开。

## 启动

需要先装好 [uv](https://docs.astral.sh/uv/) 和 Node.js。

1. 配置密钥（二选一）：
   - 把 `.env.example` 复制成 `.env`，填上 `ZHIPU_API_KEY`；或者
   - 先启动，再到界面的「设置」页填写
2. 双击 `start.bat`。它会开两个窗口分别跑后端和前端，然后打开 <http://localhost:5173>。
   关掉这两个窗口就是停止。

手动启动的话，开两个终端：

```bash
cd backend
uv run uvicorn app.main:app --port 8000
```

```bash
cd frontend
npm install   # 只有第一次需要
npm run dev
```

第一次用建议先到「设置」页点「保存并测试连接」，确认两个模型都能用。

## 使用提示

- 录入一张截图大约要 30–60 秒，时间几乎都花在模型看图上；页面会显示进度。
- 同一份内容重复录入会被识别出来，可以选择「重新处理」。
- 现在所有笔记都会进「待整理」（`vault/inbox/`）：分类表 `vault/taxonomy.yaml` 还是空的，
  自动提议分类的功能尚未实现。这不影响检索和问答。
- 在 Obsidian 里增删改笔记后，到「笔记」页点「同步」（重启后端也会自动同步）。

## 目前的限制

- 只支持截图和 2000 字以内的文本，不支持 PDF、长文、网址。
- 检索是字面匹配加模型扩展检索词，没有向量检索；笔记超过几百条后效果会下降。
- 录入任务的进度只存在内存里，重启后端后查不到（已写入的笔记不受影响）。
- 只在本机使用：后端没有登录和权限控制，不要暴露到公网。
